# @deepseek-ai/dsh-client-ui-codex-library

[English](README.md) | 中文

## 概述

工作 Codex 对话仍是所属工作区中的常规 Harness 会话，保留工具、审批、来源标记与输入框。Dot 是独立连续的原始网站对话，只能通过侧边栏顶部按钮打开。它不是常规会话、侧边栏历史条目或聊天启动器。

## 使用

将此 UI 与[原生对话服务](../../experimental/native-conversations/README.zh.md)、标准会话与工作区服务及资源注册表一起挂载。**原生对话**面板配置连接并同步已有工作 Codex 对话。工作 Codex 登录、选择其订阅供后续聊天使用、原生工具、权限与审批路由均保留原有负责组件。

**设置 → 常规**中的**启用 Dot 集成**与**在侧边栏显示 Dot**是分别保存的独立选项。两项均启用且已安装的原生集成可用时，专用按钮显示在**新会话**正下方。它使用实际选定的标题，例如 **Axiom**；未选择时使用 **Dot**。**Dot 按钮样式**提供与新会话一致、简洁与轮廓，均使用相同的共享几何。集成默认启用，侧边栏默认隐藏；已有私有配置缺少样式字段时按默认样式读取，不改写文件。

只有该顶部按钮打开专用 Dot 界面。连接面板中的**连接 Dot**配置原始网站，不导航到此界面，也不创建会话。应用内 ChatGPT 登录为主要方式，状态保留在专用网站会话中；[常规浏览器伴随扩展](../../../docs/fork-release/axiom-browser-bridge.zh.md)为可选方式。打开设置保留已选连接模式。Codex 登录不会认证 ChatGPT 网站。

专用界面通过可信桌面桥接直接读取经过验证的快照与来源事件，并通过原始输入框发送用户原文。Dot 不创建 Host 智能体、Harness 会话或 LLM 轮次。消息保留原始来源 ID 与 DOM 时间顺序；自主回复是独立消息，不组成交替的本地轮次。更早页面去重后前插，以原始 ID 维护视口锚点，并在可变高度 Markdown 完成测量后继续保持位置。时间线采用虚拟化，无客户端消息总数上限。更早历史能力缺失或超时时明确报告不可用并提供重试，不虚构历史已到起点。

Dot 专用界面使用原始网站的深色背景、字体、灰色与紫色气泡、日期分隔线及圆角输入框。只有用户位于底部时才自动跟随；初次估计滚动不会请求更早页面。失败或结果未知的提交保留用户草稿，不自动重试，也不生成虚构来源消息。

原始页面连接后在隐藏状态运行，为专用对话提供支持。**打开 ChatGPT**会显示它以直接交互。明确关闭页面后会断开连接，直到再次选择顶部按钮。禁用集成会撤销来源访问。旧 Axiom 会话日志保留，但摘要与搜索结果隐藏；通用呈现路由在保留会话引用前，将保存或直接访问的旧地址转到专用界面。不注册旧 Axiom 来源标记、常规消息渲染器或普通聊天操作。

<a id="model-experience"></a>
## 模型体验

无，因为此客户端 UI 不添加模型可见的提示词或工具。

#### KV Cache 影响

来源标记和连接状态不进入模型上下文。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 连接状态按需刷新；等待中的 Codex 登录也会轮询完成状态。连接状态不能证明某轮对话或审批已完成，实际结果由会话显示。
- Dot 需要可用的桌面桥接与原始网站。不支持的布局或尚未加载的更早历史会明确报告。本 UI 不复制凭据，也不模拟 Dot 人设。
