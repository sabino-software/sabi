# 原始 Dot 页面适配器

桌面桥接将用户选定的原始 `https://chatgpt.com/dots/<id>` 页面投影到 Harness 原生控件。它使用独立的持久化 Electron 会话，不复制浏览器 Cookie、不读取令牌存储、不调用 ChatGPT 私有 API，也不用模型请求替代 Dot。原始网站拥有对话和身份验证。**显示原始页面**会打开该网站，供用户直接登录或执行原生投影无法表示的交互。

投影仅包含页面已渲染的用户和助手 `.message-text` 元素，保留原始 ID、角色、时间戳和支持的 Markdown 格式。操作按钮、正文外的引用回复、脚本、隐藏节点以及自动图片加载均被排除。投影最多包含 100 条已渲染消息，文本量有上限；它不承诺提供尚未加载或被虚拟化的历史。网站状态文本按实际观察显示，仅存在输入指示器不表示 Dot 正在工作。

发送必须由用户在原生界面明确触发。适配器拒绝覆盖原始页面中非空的草稿，通过 Electron 输入插入原文，核对文本后点击原始页面上已启用的发送控件。Dot 工作期间能否排队由原始网站决定。确认发送需要原始页面出现具有新 ID 且文本匹配的用户消息。结果不明确时不会自动重试；请求 ID 在应用进程内防止重复点击。原始 DOM 变化可能使适配器不可用，而不会生成虚构内容。

桥接初始仅允许 ChatGPT 同源导航。跨源登录重定向必须先观察其目标，再由原生所有者允许。登录与流式更新的验收需要运行中的原始页面证据；仅有测试夹具选择器不能证明其成功。
