# 原始 Dot 页面适配器

[English](axiom-native-bridge.md) | 中文

Sabi 的可选 Dot 集成在专用连续视图中显示原始 `https://chatgpt.com/dots/<id>` 对话，只能通过侧边栏顶部按钮进入。它不创建 Harness Session 或模型轮次。原始 ChatGPT 网站拥有引擎、消息、认证与提交规则。适配器不使用其他模型请求替代 Dot，不复制浏览器 Cookie，不读取令牌存储，也不调用私有 ChatGPT API。

## 选择与登录

**设置 → 常规**中的**启用 Dot 集成**与**在侧边栏显示 Dot**是分别保存的独立选项。集成默认启用，侧边栏显示默认关闭。**Dot 按钮样式**提供默认的**与新会话一致**、**简洁**与**轮廓**三种选择，共用新会话几何。两项均启用且已安装的原生集成可用时，选定 Dot 的名称（如 **Axiom**）显示在**新会话**正下方；未选择时显示 **Dot**。无需输入网址。按钮打开专用视图，并在需要时选择原始网站。设置只配置连接，不打开对话。后台网站更新不会导航工作区。禁用集成和卸载插件会取消等待中的选择。

旧 Dot 镜像日志保持不变，但不出现在普通会话列表、搜索或会话选择器中。保存的导航和直接旧镜像链接会被拦截，不打开 Dot，也不载入旧会话。只有顶部按钮打开 Dot 对话。工作 Codex 会话保持普通 Session 行为。

主要连接使用独立的持久化 Electron 网站会话。登录发生在真实 ChatGPT 与允许的身份提供方页面；Codex 登录不会认证此网站会话。[常规浏览器伴随扩展](axiom-browser-bridge.zh.md)是可选后备方式，登录保留在所选浏览器配置中。打开连接面板会保留已保存的连接模式。连接后原始页面在隐藏状态运行，支持原生历史、发送与回复。**打开 ChatGPT**会显示它以直接交互，**重新加载页面**会刷新它。**关闭页面**会销毁页面和子弹窗并停止观察。后台观察不能重新打开它；再次明确选择 Dot 后，会使用保留的网站会话重新连接。此应用内连接无需浏览器扩展或 DeepSeek 账户。

## 原生内容与发送

投影仅包含原始用户和助手 `.message-text` 正文，保留原始 ID、来源顺序、角色、时间戳与支持的 Markdown。每行独立读取；Dot 自主更新不会被组合成人工交替的轮次。嵌套引用消息不会成为额外时间线事件。操作按钮、正文外引用回复、脚本、隐藏节点和自动图片加载均被排除。专用主题遵循原始页面的深色背景、紫色用户气泡、柔和助手气泡及对话间距。

最新快照最多包含 100 条消息。向上滚动使用准确来源 ID 请求前面的分页，不限制整段对话的消息总数。先读取原始页面已加载的前序消息。没有已加载的前序消息时，独立且延迟创建的隐藏顶层 `BrowserWindow` 使用同一保留的网站会话与滚轮输入载入更多内容。它不影响主认证页面及其可信控件，无需扩展或 CDP。

滚动到顶部后，历史页面可能需要先向下移动一个像素，再向上滚动，才能触发网站加载下一页。适配器只在加载新行或明显向上移动时更新 20 秒停滞时限；一个像素的往返移动不会更新时限。单次请求的绝对时限为 90 秒，每次渲染进程读取仍限于五秒。取消和来源变化会撤销后续输入。这些观察只用于分页，不会被记录或上报。

权威 `sourceOrder` 包含正文缺失的原始行 ID，因此恢复正文不会改变时间线顺序。CSS 虚拟化不会移除游标身份；隐藏正文仍被排除。旧内容必须先在原始页面实际加载，才能显示在原生界面中。适配器不会根据超时或空结果推断已到历史起点：没有经验证的来源边界时，报告可重试的不可用状态，并保留仍有旧历史的可能。可选浏览器伴随扩展不提供旧历史分页。网站状态按观察结果显示，仅有输入指示器不能确定活动状态。

发送需要用户在原生界面明确输入。适配器拒绝覆盖原始非空草稿，通过所选传输方式插入原文，核对后点击真实且已启用的发送控件。Dot 工作期间能否排队提交由 ChatGPT 决定。确认发送需要出现具有新原始用户消息 ID 且文本匹配的消息。当后台渲染遗漏正文时，有界内存缓存只会在该 ID 的已观察来源位置保留已确认的用户原文；实际 DOM 正文优先，页面生命周期变化会清空缓存。不明确的提交会报告且不自动重试；进程内请求 ID 防止重复点击。DOM 变化可能使适配器不可用，不能成为生成虚构来源内容的理由。

## 导航与验证

已绑定对话的导航允许选定 Dot、ChatGPT 认证路由及 OpenAI 授权服务。明确显示的认证流程还允许配置的 Google、Apple 与 Microsoft 身份来源。可见选择器在未绑定时允许 ChatGPT 选择页面；不相关来源与浏览器协议仍被阻止。原生快照排除认证查询字段和凭据。分支默认关闭报告，但原始网站与身份提供方仍保留自身遥测和网络行为。

安装核心版检查确认了持久化的应用内认证、一次原生发送与观察到的原始回复、已登录状态下重新加载、隐藏页面交互，以及明确关闭并重新打开后无需再次登录。这些检查实际使用真实网站，而不只依赖夹具或可选浏览器伴随扩展。安装核心版检查还通过隐藏历史窗口从真实网站载入了一页旧消息。每个最终产物都须重复原生发送与回复、重新加载、关闭、明确重新连接、多页分页及像素锚点检查。本地检查不能证明托管 CI 验收；后者要求目标提交的任务成功，且源码 SHA 与产物一致。该边界见[发布验证流程](plan.zh.md)。
